**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.5.0, controls for keeping a server to quick work (a preview server that has to keep up with many
requests). Clients see each change in the operations' descriptors, and a request past it is refused.

- **Caps on a model:** `gaea models limit <id> <field> <value>`, by MES limit name: `max_megapixels`, `max_side`,
  `max_duration_s`, `max_frames`, `max_count`, `max_faces`, `max_texture_size`, `max_text_chars`, `max_source_s` or
  `max_layer_count`.
  - `gaea models limit klein-4b max_megapixels 4.2` keeps FLUX.2 Klein to 2048² instead of 4096².
  - A cap narrows the offer clients see and the limits Gaea plans by. It never widens what the plugin offers.
  - A mesh offer whose default is above a cap is made at the cap, with `faces_reduced` or `texture_reduced`.
  - `… <field> none` removes one cap, and `gaea models limit <id> none` removes them all.
- **Lanes off:** `gaea models lanes <id> off <lane>`.
  - A switched-off lane is never chosen, not even as a fallback, and a request that names it is refused.
  - The default moves to the next lane, and a model with every lane off isn't offered.
  - `… on <lane>` switches it back.
- **A saved budget:** `gaea budget <GB>` sets the memory budget now and for later launches, and `gaea budget default`
  goes back to three quarters of memory.
  - `gaea budget` reads it and lists the models it leaves out.
  - `gaea status` says where it comes from.
  - `--budget-bytes` still sets one for a launch.
- `gaea models` shows each model's caps and switched-off lanes. Caps, lanes and the budget are kept in gaea.sqlite and
  survive restarts and updates.
