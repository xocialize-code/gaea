**Gaea 1.0.0 is still alpha.** 1.0 marks the end of Gaea's production phase (G4). It does not freeze the MES API.
More plugins are coming, AuK first, and they may change the MES spec and Gaea with it. Expect breaking changes, and
read each release's notes before you update.

What 1.0 was checked against:

- **A clean install:** from this GitHub release on a Mac that had never seen Gaea, a throwaway macOS 26 VM. The app
  and headless Gaea serve, and a plugin installs and runs on the guest's GPU.
- **A 24-hour soak:** mixed image, audio and video jobs, a crash injected every hour, and a self-update part-way
  through. All 7,413 jobs succeeded, and the update answered in 63 s.
- **A second team:** a plugin signed and notarized by another Developer ID team is held, approved, run beside our own
  plugins, and stopped when its team is removed.
- **Conformance:** MES Base, Image, Audio and Video 0.1 all conform with all 22 released plugins installed.

The soak found a leak in mlx-swift that killed LTX's worker after about 379 runs. Install LTX 0.1.3 or newer
(`gaea plugins update`) for the fix.
