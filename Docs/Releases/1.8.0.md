**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.8.0: Gaea is on mlx-engine-swift 0.79.0, so plugins built on it install and run. The first is
gaea-plugin-trellis2 0.2.0.

- **Pixal3D**, in the TRELLIS.2 plugin (`gaea plugins update com.xocialize.gaea.trellis2`). Two new 3D models,
  `pixal3d-1024` and `pixal3d-1536`, that follow the photo pixel for pixel through a camera. Stock TRELLIS.2 invents
  what it can't tell from the picture; Pixal3D keeps the shape the photo shows on thin and layered subjects.
  - They run only when a request names them.
  - `x-pixal3d.fov` is the photo's horizontal field of view, 20° by default. That suits a studio product shot; give a
    phone or wide-lens photo its own.
  - Each has two lanes that give the same mesh: `bf16` (71.3 and 76.2 GB) and `bf16-lowmem` (60.3 and 65.2 GB, 8 to
    15 % slower). Gaea falls back to `bf16-lowmem` when `bf16` doesn't fit.
- **Detail maps on every TRELLIS.2 and Pixal3D model:** `x-trellis2.normal_map` and `x-trellis2.ao_map` add a normal
  map and an ambient-occlusion map at the texture's size. Both are off by default.
- **Valid normals.** The plugin's meshes now pass the Khronos glTF validator: a few vertices used to carry zero-length
  normals.
- **For plugin authors:** GaeaPluginKit 0.14.0 is on mlx-engine-swift 0.79.0 (contract 1.64.0, typed cameras on image
  to 3D). A plugin built on it needs Gaea 1.8.0.

Nothing changes for the plugins already installed.
