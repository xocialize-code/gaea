**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.3.0, from Gaea's first real client (Craft Anything, AB-A-0259):

- **A first job says what it's waiting for.**
  - **During the wait:** while a job downloads its model's weights or loads them, its client sees MES progress stage
    `preparing`, for example "downloading the weights (first use): 4.2 of 19.0 GB", then the load, then `running`.
  - **After it:** `x-gaea.worker.prepare_seconds` in the result says how long that took.
  - Before, the wait was silent and counted as run time. Craft Anything's first picture waited nine minutes on a 19 GB
    download it couldn't see.
- **No more surprise downloads.**
  - **On install:** `gaea plugins add` names any weights it doesn't find under the models root.
  - **In the list:** `gaea models` marks a model whose default lane would download on its first job.
  - **Ahead of time:** `gaea plugins warm <id> [model] [lane]` downloads and loads them now, so nobody waits.
  - **Check the root:** if a model you already have is marked, the models root probably points at the folder above
    your snapshots.
- **Idle unload is a setting.** `gaea workers idle <seconds>` sets how long a worker may sit idle before Gaea stops it
  and frees its memory (900 s by default; `--idle-seconds` still sets it for one launch), and `gaea status` shows it.
- **Still to come, from media-engine-spec and the image normalizer (AB-A-0260):**
  - MES's own `prepare_ms`;
  - the idle policy on `GET /health`;
  - RGB PNGs for opaque pictures.
