**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.1.0:

- **`audio.separate` (MES 0.10, RFC 0006).** A mixture in, one audio output per stem out, each named by its stem and
  the mixture's length. The descriptor lists the stems the installed plugins make. A mixture longer than an offer's
  limit is refused, never trimmed. AuK's plugin, the first real separator, comes next; the demo plugin (0.4.0) has a
  stand-in for testing.
- **MESKit 0.10.0:** `edit_speech` gains `dereverb`, the `hum` cue, `target_duration_s`, and per-offer cue placement.
- **For plugin authors:** GaeaPluginKit 0.11.0 maps MES edits and separations to the engine's requests
  (`SpeechEdits`, `AudioSeparations`) and builds on mlx-engine-swift 0.74.1. Step-Audio-EditX 0.1.2 uses it.
