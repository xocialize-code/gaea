**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.10.0: which plugins Gaea will run changes, and Gaea reads plugins built for a newer engine.

- **A plugin now needs a Developer ID signature and Apple's notarization, not a place on a list of developers.**
  - A notarized plugin installs and runs whoever signed it, with no question. Before, a plugin from any team but ours
    was held until you approved the team.
  - **What that means for you.** Apple's notarization scans a build for malware and records who signed it. It doesn't
    review what a plugin does, and a plugin runs unsandboxed, as you. Add plugins from developers you have a reason to
    rely on.
  - **A build that isn't notarized** still runs only from a team on the trust list (ours, and the teams you approve),
    and is held for your answer otherwise. `gaea trust` works as before for those.
  - **An update signed by another team** than the plugin it updates is held once for your answer, notarized or not.
  - `gaea trust remove <team>` now stops only that team's plugins that aren't notarized. To stop a notarized plugin,
    disable or remove it.
- **Gaea is on mlx-engine-swift 0.83.0**, so it reads manifests that declare the engine's typed `imageLocate`
  capability. gaea-plugin-locate 0.2.0 uses it and needs this release: with more instances in the picture than
  `count`, it returns the best `count` by score, where 0.1.x returned the model's first.
- **A model is opt-in when any licence among its weights is restricted**, not only the first one a package names.
  No released plugin changes: the one affected, FastFrames, already said so itself.
- **For plugin authors:** nothing in GPP changes. A plugin from your own team installs without the operator
  approving the team, once its release is notarized.

Nothing changes for the plugins already installed.
