**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's fixed in 1.1.1:

- **Plugins built on mlx-engine-swift 0.74.1 install.** 1.1.0 read manifests with the 0.73 engine's types, so a
  manifest listing contract 1.59.0's speech edits (`dereverberate`, `hum`) didn't decode and the plugin couldn't be
  installed. AuK's plugin (0.1.0) was the first to list them. Gaea now builds on mlx-engine-swift 0.74.1 and
  GaeaPluginKit 0.11.0, the versions the plugins build on. Older manifests decode as before.
