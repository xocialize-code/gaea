**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.4.0 (AB-T-0467):

- **3D: MES Mesh 0.1.** Gaea serves `mesh.generate` (one picture → a textured GLB) from plugin offers, beside Image,
  Audio and Video (media-engine-spec v0.11.0, RFC 0007). Around the plugin's mesh, Gaea:
  - cuts the object out where the offer can, or uses a picture that already has transparency as it is (`background`);
  - centres the result, or stands it on the ground with `placement: grounded`, and scales it to `size_m` (1 m by default);
  - marks it AI-generated and writes the model's licence and attribution into the file;
  - renders a 768² preview PNG with the mesh's own texture, for clients without a 3D viewer.
- **The first 3D plugin: TRELLIS.2** (`gaea plugins add https://github.com/xocialize-code/gaea-plugin-trellis2`). It
  offers three models, one per resolution, each charged the memory it takes:
  - `trellis2-512`: draft and standard, about a minute, 38 GB;
  - `trellis2-1024`: best, 8 to 9 minutes, 69 GB;
  - `trellis2-1536`: for `resolution: 1536`, 7 to 11 minutes, 72 GB.

  Built with DINOv3.
- **Tiers on a preview server.** Switching models off is how an operator keeps a server to the quick tiers:
  `gaea models disable trellis2-1024` (and `trellis2-1536`). The server then offers only the qualities its remaining
  models serve, and refuses the rest.
- **What clients see of the server's memory policy** (AB-A-0260, media-engine-spec v0.12.0):
  - `GET /health` states the idle unload (`memory.idle_unload_s`, `gaea workers idle`);
  - `resident_until` says when each loaded model will be unloaded if it stays idle;
  - every job's timings report `prepare_ms`, the time spent downloading or loading its model.
- **Opaque pictures come back as RGB PNGs** (pixel-agency-normalizer 0.3.1), smaller than the RGBA they were.
- **For plugin authors:** GaeaPluginKit 0.12.0 adds companion models. A model can declare another engine model of its
  plugin that its runs call, such as a matting step. Preparing the model prepares the companion, and its weights count
  as the model's for first-use notices and `gaea plugins warm`. GPP-1 §3.3.4 says how meshes travel.
