**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.6.0: `audio.separate` by description (MES 0.13.0, RFC 0008), for plugins whose model separates the
sound a request describes, such as SAM-Audio.

- **`describe`:** a request names the sound in a few words, and the job returns it as the `target` stem with the rest of
  the mixture as `residual`. `effective.describe` says what the model was given.
- **`spans`:** a request can say where the sound is heard or isn't, as `{start_s, end_s, present}`.
  - Spans that overlap, or end at or before they start, are refused when the request arrives (400).
  - A span that ends more than a sample after the mixture does is refused `out_of_limits` when Gaea reads the
    mixture. Gaea never clips one.
- **Offers** state `supports.described_target`, `supports.spans` and, for a model that marks its outputs,
  `supports.watermark` (for example `audioseal`). A request with `describe` or `spans` to an offer without the key is
  refused (422), and so is a request without `describe` to an offer that only separates by description.
- Plugin manifests are checked against MES 0.13.0's descriptor schema, so `supports.watermark` has to be a scheme id.

No plugin released today has such an offer. The first is the SAM-Audio plugin, which needs this version.
