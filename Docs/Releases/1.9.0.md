**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's new in 1.9.0: two things a client can now ask for, on media-engine-spec 0.15.0.

- **`image.locate`: where something is in a picture.** A picture and a prompt in ("the character's head including
  the hair"), boxes out, each a share of the upright picture with a label and a score. An empty list means it isn't
  there.
  - It needs a plugin that offers it: `gaea plugins add https://github.com/xocialize-code/gaea-plugin-locate`
    (Qwen3-VL-4B, Apache-2.0, about half a second a picture, 5 GB).
  - `count` is the most boxes to return, 1 by default.
- **A subject on `image.matte`.** Give a box or points (`subject`) and the mask and the cut-out cover that subject
  alone. Without it nothing changes. It needs the Forge pack, which has both the matting model and the segmenter.
- **A request with a top-level field MES doesn't know is now refused** (400), where it was silently dropped.
- **For plugin authors:** Gaea is on mlx-engine-swift 0.80.0 (contract 1.65.0) and GaeaPluginKit 0.15.0 is on it too. A
  plugin built on that kit needs Gaea 1.9.0. GPP-1 §3.3.5 says how a worker returns boxes.

Nothing changes for the plugins already installed.
