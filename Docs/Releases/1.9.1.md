**Gaea is alpha.** MES and Gaea are still changing as more plugins arrive, so read each release's notes before you
update.

What's fixed in 1.9.1: Gaea says when it is too old for a plugin, and shows its own update where you already look.

- **A plugin that needs a later Gaea says so.** A server on Gaea 1.4.0 refused HairDeck (which needs 1.7.0) with a
  decoder's error about a capability it didn't know. Gaea now reads a release's minimum version first and answers
  "v0.1.1 needs Gaea 1.7.0 or later: update Gaea first". This helps from 1.9.1 on: an older Gaea still shows the old
  error, and the fix for it is the same, `gaea update`.
- **Gaea's own update shows in the console.** Until now a newer Gaea showed only in Settings › Updates and
  `gaea status`.
  - The status card at the foot of the console's sidebar adds a line: "Gaea 1.10.0 is available · Settings › Updates".
  - The app menu has "Check for Updates…", which reads "Update to Gaea 1.10.0…" once a newer release is known. It opens
    Settings on the Updates tab.
  - A banner and a mark on the menu bar item need a change in the console's shared UI and come later.
- **An Image model's speed comes from its plugin where Gaea's routing table has none.** Fibo 2.0 Dev now lists as
  `slow` and Fibo 2.0 Edit Turbo as `standard`; before, neither listed a speed.
- **For plugin authors:** a prompt profile can list `text_only_tasks`, the tasks it rewrites without seeing the job's
  pictures (GPP-1 §4.4, GaeaPluginKit 0.16.0). It has no effect yet: the image normalizer doesn't ask a prompt
  enhancer about edits.

Nothing changes for the plugins already installed.
